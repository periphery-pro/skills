# Periphery Skills

Agent skills for [Periphery](https://periphery.pro).

## Install

```sh
npx skills add periphery-pro/skills
```

To install a single skill, or to choose which agents to install it for:

```sh
npx skills add periphery-pro/skills --skill periphery-scan-setup -a claude-code
```

## Skills

| Skill | Description |
| --- | --- |
| [periphery-scan-setup](skills/periphery-scan-setup) | Sets up Periphery for your project with your agent's help and runs your first scan. An alternative to `periphery scan --setup`. |
